Interactive Code with Pyodide

NoteWhat are extensions?

Extensions add extra features to Quarto that are not built in. You install them once per project folder. See the full list at quarto.org/docs/extensions.

Pyodide lets students run and edit Python code directly in the browser — no Python installation needed on their computer. You write the code once; they click Run Code.

WarningHTML only

Interactive code requires HTML output. It works in websites (format: html) and books, but not in PDF or Word documents.

1 — Install the Pyodide extension

① Open the Terminal in VS Code

Open the Terminal (the command line interface) via View → Terminal. A panel opens at the bottom of the screen. Make sure the path shown matches your project folder.

② Run the install command

Terminal
quarto add coatless-quarto/pyodide

Wait until it finishes — it will ask you to confirm once. This only needs to be done once per project folder.

2 — Enable it in your file

Add a filters: line to the header block of your .qmd file:

---
title: "My Page"
format: html
filters:
  - coatless-quarto/pyodide
---

3 — Add an interactive code block

Instead of a regular code block, use {pyodide-python}:

```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```

Students can edit this code directly in the browser and run it with the Run Code button.

4 — See the result

① Preview your page

Run quarto preview in the Terminal. The code block appears in the browser with a Run Code button.

② The interactive block in the browser

At the top of the page Quarto shows PYODIDE STATUS: Ready! when Python has loaded. Students can click Run Code, edit the code, and run it again — all without installing anything.

TipWant students to fill in solutions?

The py-exercise extension adds code blocks with hidden automated tests — students see whether their solution passes or fails. The math-exercise extension does the same for symbolic/numeric answers, checked with SymPy instead of unit tests. Both have live examples on the Example Page of this tutorial.

5 — Level up: cells that share state, real input(), animations

The Code page of this tutorial’s Example Page doesn’t stop at coatless-quarto/pyodide — it runs on pyodide-interaktiv, a fork built for this project that executes Python in a Web Worker instead of on the browser’s main thread. That one change unlocks several things students immediately notice:

  • Real input() — a cell can pause and wait for typed input without freezing the page.
  • Animations — a Matplotlib FuncAnimation plays as an interactive player, from the same code you would write in a local IDE.
  • Safe infinite loops — an accidental while True: no longer locks up the tab; a Stop button cancels the worker.
  • AI feedback — every cell gets a Feedback button that explains what went wrong, with hints that get more concrete on each click.
  • A responsive page — a long calculation no longer freezes the tab, because it happens off the main thread.

(Cells sharing one Python session per page — a later cell reusing a variable or import from an earlier one — works in both versions.)

You can try all of this live on the Code page of the Example Page.

ImportantNot yet quarto add-able

pyodide-interaktiv (and math-exercise) are not published to the public extension registry yet — only coatless-quarto/pyodide is. Until they are, the only way to use the fork in your own project is to copy the folder over by hand:

① Copy the extension folder

Copy _extensions/Erasmus-CTM/pyodide-interaktiv/ from this project into your own project’s _extensions/ folder.

② Reference it by folder name

---
title: "My Page"
format: html
filters:
  - pyodide-interaktiv
---

That’s it — no quarto add step needed for a vendored extension.
